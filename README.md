# XUI2

XUI2 将原面板拆成管理端和被控端，使用 HTTPS Web API 管理多台被控端。管理端保存账号、共享流量限额、计费方式与历史汇总；被控端运行 Xray，在本机执行账号操作并记录本机流量。两种角色使用同一份程序，由安装时写入的 `XUI_ROLE` 决定。此项目按全新部署设计，不读取旧版 xui 的远程 SSH 配置。

## 安装

支持 Linux amd64、arm64，以 root 运行：

```bash
bash <(curl -fLsS https://raw.githubusercontent.com/small32/XUI2/main/install.sh)
```

安装脚本提示选择 `1) 管理端` 或 `2) 被控端`。更新时默认保留当前角色；已有数据库不能原地切换角色。脚本优先下载 XUI2 Release；没有可用 Release 时，会从 `main` 克隆源码、下载 Go 工具链与 Xray 并在本机编译。首次安装会生成 HTTPS 证书，设置管理员用户名、密码和面板端口。

被控端安装结束会显示 API 令牌和证书 SHA256 指纹。令牌也保存在仅 root 可读的 `/etc/xui/agent.env`；证书和私钥位于 `/etc/xui/panel.crt` 与 `/etc/xui/panel.key`。在管理端的“被控端管理”填写被控端的 `https://主机:面板端口`、令牌、订阅地址和指纹。使用公开可信的证书时可不填指纹。请先确保管理端可以连接被控端的 HTTPS 面板端口。

管理端默认不会启动 Xray；启用上级服务器时仅启动本机代理，不启动受管账号入站。被控端只接受管理员网页登录；端口号账号只能登录管理端，用户名为端口号、密码为该入站的服务密码。入站用户只可查看自己的账号、订阅、流量汇总、节点明细和月度历史。

## 上级服务器与本机代理

在“面板设置 → xray 相关设置”启用上级服务器，填写 Trojan、VMess 或 VLESS 的地址、端口、认证信息与 `streamSettings` 传输配置。“生成配置模版”可先预览；保存时也会自动生成上级出站和路由，重启面板后加载。现有入站及 API 配置保留。已有明确的路由规则继续优先，普通 TCP/UDP 的兜底流量使用选定的上级。

勾选“允许本机使用上级服务器代理”后保存并重启，本机 HTTP 代理监听 `127.0.0.1:10809`，SOCKS5 监听 `127.0.0.1:10808`。菜单下载、apt、面板证书续期服务和新登录终端自动使用系统代理；已有终端运行 `source /etc/profile.d/xui-proxy.sh` 加载。仅支持代理的程序使用这些设置，不接管防火墙或全机 TCP/UDP。上级域名需要本机能够解析；HTTP 代理和 `socks5h` 会将访问目标的域名交给上级解析。

关闭本机代理后保存并重启，会清理 XUI 生成的环境、apt 和证书续期代理配置；已有终端需重新登录，或执行 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY all_proxy ALL_PROXY no_proxy NO_PROXY`。本机代理使用独立标签，不计入现有入站账号额度；服务器网卡和上级账号仍会产生实际流量。

`dokodemo-door` 是固定目标转发模式：本机 `127.0.0.1:10810` 的 TCP/UDP 转发到填写的上级地址和端口，不支持通用外网代理，也不能勾选本机系统代理。

被控端“系统状态”的“网络流量”卡片在同一列显示当前上传/下载速度及当月累计上传/下载量。累计量独立统计非回环网卡，包括本机系统代理流量；后台每 10 秒保存，无需保持页面打开，面板及服务器重启后保留，按上海时区切换月份。统计从首次启用采集开始，之前的历史用量无法追溯，不参与账号共享额度结算。

## 账号、流量与重试

管理员在管理端创建、修改或删除入站后，管理端为每台启用的被控端记录独立同步任务并立即发送。失败任务留在数据库中，下一次心跳重试，页面会列出节点和错误。新增被控端时，会下发当前全部账号。被控端用管理端账号 ID 定位本地记录；修改端口时原位更新，保留已有流量。各被控端证书路径从自身面板设置提取。

管理端下发配置时，若被控端同端口已有本地入站或其他受管入站，直接以管理端配置覆盖，并绑定到当前管理端账号，保留已有流量计数。账号修改端口时如目标端口已被占用，也覆盖该端口配置并合并原有流量计数；重复下发不会重复累计。

在管理端新增或编辑账号时，可选择“所有被控端”或指定多个下发节点。指定节点的选择会持久保存，心跳、重试、重置和订阅均遵循此选择；取消节点后会清理该节点上的此受管账号。停用节点暂不接收普通配置，重新启用后补发所选账号。已有账号默认仍选择所有被控端，包含以后新增的节点。

账号编辑窗口提供各被控端的协议标签页。勾选“为此被控端单独设置协议”后，可设置该节点的协议、传输、TLS 与监听地址；未勾选的节点使用默认连接设置。备注、端口、总流量、计费方式、到期时间共用账号设置，Trojan、Shadowsocks、HTTP、SOCKS 使用上方“账号统一密码”；VLESS、VMess 的 UUID 保留各自配置。每个节点按自身连接设置计算配置版本，心跳不会将节点专属协议改回默认协议。

生成订阅时合并所选启用节点的实际链接，二维码窗口按节点名称和实际协议分别展示二维码。HTTP/SOCKS 链接使用订阅转换器支持的类 Telegram 链接格式，参见 [subconverter 支持格式](https://github.com/tindy2013/subconverter/blob/master/README.md)。

默认每 10 分钟读取一次所有被控端流量，可设置更长间隔，也可在页面立即刷新。流量限额由所有被控端共同消耗；合计上传和下载达到管理端账号限额时，管理端向所有被控端下发停用。未超限时不修改启用状态。过期账号同样停用。手动停用与超限停用分别记录原因。某个节点断线、账号版本落后或数据过期时，页面显示“未确认”及最近错误；断线期间实际用量可能超过共享限额，连接恢复后会补采并处理。

被控端本地创建或通过跨节点复制生成的入站也会被采集，在“流量汇总”按节点单独显示，来源标为“节点名称（本地入站）”。本地入站端口与管理端受管账号相同时，其用量合并到该账号的共享额度及节点明细；没有匹配受管账号的本地入站按节点单独展示。可以点击“读取最新被控端流量”立即采集，读取失败时保留上次用量并标为“未确认”。此功能需要管理端与被控端同时更新。

按月计费的账号在每月切换时留档并重置计数；累计计费账号不会自动清零。被控端会独立保存月度原始快照，管理端断线后可通过幂等重置接口补取并汇总历史。若被控端本身跨月离线、无法还原某个月的原始流量，接口明确报错，不会把多个自然月的数据静默归入一个月。月度重置全部完成后，原先因超限停用的账号才会恢复启用。管理端数据库中的操作队列及被控端的重载标记用于处理网络故障和 Xray 重启失败。

已有节点的 API 地址不可直接修改。更换服务器时，先删除旧节点并确认远端账号清理完成，再添加新节点；修改同一服务器的证书指纹不会清空待同步任务。正常删除被控端时，管理端先删除其受管账号；如果节点不可达或还有待同步任务，节点仍保留在管理端。旧服务器已无法连接时，可使用“强制移除”，但必须自行停机或清理旧服务器上的账号；强制移除不检查节点连接或月度任务状态，直接清除该节点及其全部同步任务、当前流量记录；已完成的历史流量快照保留，未完成的月度结算不再补采。

## 被控端 API

管理端的“被控端管理”页面提供独立的“被控端入站设置”标签页，其中按被控端在管理列表中的名称分标签读取全部入站（包括本地创建的入站）。可以全选或勾选部分入站，再选择一个或多个其他被控端同步。每个目标、端口单独显示成功或失败，失败项可重新选择后再同步。管理端和被控端都需要更新到支持此功能的代码版本。

此操作将配置复制为目标端的本地入站，不复制来源的已用流量或管理账号 ID。目标同端口默认跳过；勾选覆盖时仅覆盖本地入站，并保留目标已有流量。受管入站仍通过管理端原有账号同步机制配置。文件证书路径取自目标端面板设置，保存后立即请求重载 Xray。

API 位于被控端 HTTPS 面板的 `/api/v1`，使用独立的 `Authorization: Bearer <API令牌>`。明文 HTTP、缺失令牌和错误令牌均被拒绝。自签名证书由管理端按 SHA256 指纹校验。API 仅供管理端后端调用；浏览器不保存被控端令牌。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/capabilities` | 检查 API 版本 |
| GET | `/inbounds` | 查询全部受管账号 |
| GET | `/inbounds/all` | 查询全部入站，包含本地入站 |
| PUT | `/inbounds/copy/{port}` | 复制配置为本地入站，支持覆盖本地同端口配置 |
| GET | `/inbounds/{port}` | 查询指定端口账号 |
| PUT | `/inbounds/{port}` | 按管理端账号 ID 新增或修改 |
| DELETE | `/inbounds/{port}` | 删除指定账号 |
| GET | `/traffic` | 查询各账号本机流量及状态 |
| POST | `/inbounds/{port}/disable` | 按超限或过期原因停用 |
| POST | `/inbounds/{port}/traffic/reset` | 幂等重置并返回重置前流量 |

新增或修改示例：

```http
PUT /api/v1/inbounds/34872
Authorization: Bearer <token>
Idempotency-Key: <operation-id>
Content-Type: application/json

{"managerAccountId":42,"managerRevision":"<64位配置摘要>","port":34872,"protocol":"trojan","settings":"{\"clients\":[{\"password\":\"secret\"}]}","streamSettings":"{}","sniffing":"{}","remark":"客户 A","enable":true,"total":107374182400,"monthlyReset":true}
```

流量响应示例：

```json
{"observedAt":1790121600,"inbounds":[{"accountId":42,"port":34872,"up":1200000,"down":3400000,"enabled":true,"disabledBy":"","managerRevision":"<64位配置摘要>"}]}
```

月度重置请求包含 `accountId`、上一自然月编号 `period`（如 `202609`）及唯一 `operationId`。被控端对同一月份保存一次快照，重复调用返回相同的重置前用量，不会再次清零。

## 开发

```bash
go test ./...
go build ./...
bash -n install.sh
```

Release 工作流仅在推送版本标签或手动触发时运行。`config/version` 当前为 `0.2.1`；提交到 `main` 不会自动发布 Release。
